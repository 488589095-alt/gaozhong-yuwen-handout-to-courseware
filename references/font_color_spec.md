# 字体 / 颜色规范（甲方确认版，第2讲古诗 case 定稿）

> 这套规范是和甲方多轮校对后的定稿。其中「古诗楷体、题目黑体、注释仿宋」是**甲方明确指定**
> （标杆课件里诗实测是黑体，但甲方要楷体——以甲方为准）；其余照标杆课件实测。
> 改动任何一项前先和用户确认。

## 为什么是这套（踩坑记录）

- 第一版全按标杆实测（诗=黑体）→ 甲方不接受，明确"古诗楷体，题目黑体，注释仿宋"。
- 第二版全改楷体 → 甲方批评"怎么全改楷体了"。**教训：别按主观印象统一字体；
  先逐元素提取标杆 ea（`<a:ea typeface>`），列分布表给用户确认，再写代码。**
- 字体名用「楷体/黑体/宋体/仿宋/微软雅黑」（WPS/Office 中文版通用）。
  LibreOffice 预览缺字会 fallback——预览只能看排版颜色，**真实字体必须在 WPS/PPT 验**。
