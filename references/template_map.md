## 关键坑（不删贴图必翻车）

模板的"示例内容"是**图片贴在 slide 上**（不在 layout 上），克隆时会原样带过来，
与新内容重叠成一团。上表加粗的"删 Image X"一个都不能少——第2讲 case 里
T3/T16/T17 的贴图都翻过车（"空间几何体"串字、数学题垫底、练习页公式横幅）。

## 克隆技术要点

- **必须带关系重映射**：本模板每页几十张图片直接挂 slide，`copy.deepcopy(spTree)` 后
  `r:embed` 指向源页 rId，新页没有 → 图全裂。`clone_slide()` 把源页 rels 逐条
  `relate_to()` 到新页并改写引用（REF_ATTRS 覆盖 r:embed/r:link/r:id 等）。
  验证手段：克隆后逐 pic 读 `sh.image.blob`，0 异常才算成功。
- 构建顺序：按目标页序克隆追加到尾部 → 末尾从后往前删原 22 张样本页 → 顺序天然正确。
- 标杆课件（第2讲-S班.pptx）= 此模板 + 内容，坐标互通，可作排版坐标参照。
